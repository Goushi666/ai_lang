# 后端设计 · 目录结构

```
backend/
├── app/
│   ├── api/
│   │   └── v1/
│   │       ├── sensors.py       # 传感器
│   │       ├── alarms.py        # 告警
│   │       ├── vehicles.py      # 车辆/云台/机械臂/循迹
│   │       ├── devices.py       # 设备
│   │       ├── analysis.py      # 环境分析
│   │       ├── monitoring.py    # 环境监测页 API
│   │       ├── agent.py         # 智能 Agent（对话、知识库 HTTP、感知记忆）
│   │       ├── auth.py          # 注册/登录/JWT、用户级别（含 admin）
│   │       ├── video.py         # 视频代理/配置
│   │       └── admin.py         # 数据维护、知识文档上传、FTS 导入/清空（admin 权限）
│   ├── core/
│   │   ├── config.py
│   │   ├── database.py          # SQLAlchemy 引擎与会话
│   │   ├── security.py
│   │   ├── mqtt.py
│   │   └── timeutil.py          # 时间格式化等
│   ├── models/                  # ORM
│   ├── schemas/                 # Pydantic
│   ├── services/
│   │   ├── sensor_service.py
│   │   ├── alarm_service.py
│   │   ├── auth_service.py        # 注册登录、JWT、首用户 admin 规则
│   │   ├── vehicle_service.py
│   │   ├── analysis_service.py
│   │   ├── monitoring_service.py    # 监测页温度时间线等
│   │   ├── temperature_forecast.py  # 温度预测（LSTM 等）
│   │   ├── knowledge/               # 知识库：分块 + SQLite FTS5 检索（KnowledgeService）
│   │   │   ├── chunker.py
│   │   │   └── service.py
│   │   └── agent/               # 智能 Agent（LangGraph 编排）
│   │       ├── service.py
│   │       ├── graph/           # build/state/nodes、safety、tool_tier、SSE 辅助
│   │       ├── memory/          # 多层记忆（working + 聚合 service）
│   │       ├── clarifier.py
│   │       ├── tools/           # BaseTool、传感器/告警/分析/知识/导出/时间/车辆
│   │       ├── llm/             # client、prompts、reasoning_split
│   │       ├── context/         # SessionManager
│   │       └── skills/          # Skill 注册（如 env_diagnosis）
│   ├── repositories/
│   ├── websocket/
│   ├── middleware/
│   └── main.py
├── knowledge_docs/            # 说明文档 Markdown（与设置页/admin 导入目录一致，配置 KNOWLEDGE_DOCS_DIR）
├── scripts/
│   └── ingest_knowledge_docs.py # 命令行入库 FTS（可选；管理端亦可一键导入）
├── data/
│   ├── app.db                   # 主库（示例路径，以运行环境为准）
│   └── knowledge_fts.db         # 知识 FTS（默认 KNOWLEDGE_SQLITE_PATH，可 .gitignore）
├── requirements.txt
└── .env
```

依赖方向保持 **api → services → repositories**；设计文档以仓库实际文件为准，若有新增路由或服务，同步更新本节。
