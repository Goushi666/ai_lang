# PRD：工业巡检与遥控 Agent（快速、准确、可控）

## 1. 产品背景
当前“巡检与遥控”页面已具备视频、状态、云台、车辆与机械臂控制能力，但整体仍以手动操作为主。  
目标是引入一个工业级 Agent，实现“分析-决策-执行-验证”闭环，在保证安全的前提下提升响应速度与处置准确率。

## 2. 产品目标
- 效率目标：异常发现到动作执行平均耗时下降 40%+
- 准确目标：执行成功闭环率（执行+验证成功）> 95%
- 安全目标：高风险动作 100% 二次确认；误执行率 < 0.5%
- 可追溯目标：每次决策与执行全链路可审计

## 3. 目标用户
- 值班运维人员：快速获取告警与建议，批准执行
- 现场控制人员：半自动/手动接管，执行精细操作
- 管理员：配置规则、权限、阈值与审计策略

## 4. 关键使用场景
- 传感器温度持续超阈 -> Agent 提出巡检路径 + 云台角度 -> 人工确认 -> 自动执行 -> 回执验证
- 巡检车状态异常（如速度反馈异常）-> Agent 自动降级（停止/回滚）-> 发出人工接管提示
- 夜间巡检模式 -> Agent 按预设任务周期执行并生成结构化报告

## 5. 功能设计（建议分阶段）

### 5.1 Phase 1（MVP）

#### 5.1.1 Agent 控制台（新增）
功能：
- 展示 Agent 状态：待命 / 分析中 / 待确认 / 执行中 / 回滚中 / 完成
- 展示建议动作卡片：动作列表、风险级别、置信度、证据来源
- 操作按钮：批准执行 / 拒绝 / 一键接管手动

价值：
- 让自动化可见、可控，降低黑盒感。

#### 5.1.2 结构化决策输出（核心）
功能：
- Agent 仅输出标准 JSON（意图、动作、参数、证据、置信度）
- 禁止自由文本直接触发控制

价值：
- 降低幻觉直接进入执行链路的风险。

#### 5.1.3 执行前规则校验器（Validator）
功能：
- 参数范围校验（速度、角度、时长）
- 模式校验（循迹/普通互斥）
- 权限校验（不同角色是否可执行）
- 危险动作二次确认（如移动类动作）

价值：
- 把错误阻断在执行前。

#### 5.1.4 执行后验证与回滚
功能：
- 执行后自动检查 telemetry（状态、速度、模式）
- 验证失败自动停止/回滚 + 告警 + 人工接管提示

价值：
- 形成闭环，确保动作有效。

#### 5.1.5 审计日志中心
功能：
- 记录输入上下文、Agent 输出、规则校验结果、执行结果、验证结果、操作者
- 支持按时间/会话/设备检索

价值：
- 可复盘、可追责、可优化模型。

### 5.2 Phase 2（增强版）
- 自动巡检任务编排：支持定时、周期、事件触发三类任务；支持路径模板与动作模板
- 异常处置策略库：异常类型绑定 SOP；支持建议动作优先级与冲突解决
- 多模态增强分析：视频帧 + 传感器 + 历史数据联合判断
- 质量看板：成功率、误执行率、人工接管率、平均处置时长

### 5.3 Phase 3（高级工业化）
- 多 Agent 协同：分析 Agent、执行 Agent、审计 Agent 分离
- 数字孪生/仿真回放：上线前策略回放与风险评估

## 6. 防幻觉机制（必须项）
- 仅结构化输出（Schema 强约束）
- 无证据不执行（evidence 必填）
- 低置信度自动降级人工确认
- 高风险动作强制双确认
- 规则引擎优先级高于模型
- 执行后必须验证，不通过即回滚
- 全链路日志保留（可审计）

## 7. 非功能要求
- 决策延迟：P95 < 800ms（不含设备执行时间）
- 指令下发稳定性：99.9%
- 前端状态刷新与回执时延：< 300ms
- 异常降级策略：Agent 不可用时自动回手动模式

## 8. 关键指标（上线验收）
- 异常处置平均时长（MTTR）
- 自动执行成功闭环率
- 误执行率 / 漏执行率
- 人工接管率
- 告警误报率
- 用户满意度（运维侧问卷）

## 9. 里程碑（建议）
- 第 1 周：Schema + Validator + UI 控制台草图
- 第 2 周：MVP 执行链路联调（分析 -> 校验 -> 执行 -> 验证）
- 第 3 周：日志中心 + 权限 + 二次确认
- 第 4 周：灰度发布 + 指标看板 + 调参

## 10. 实施优先级建议
优先做（必须）：
1) Agent 控制台  
2) 结构化决策输出  
3) 执行前规则校验器  
4) 执行后验证与回滚  
5) 审计日志

后做（增强）：
1) 自动巡检任务编排  
2) 异常处置策略库  
3) 多模态增强与质量看板
