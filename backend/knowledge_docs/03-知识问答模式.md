# 知识问答模式（客户端说明）

## 智能助手上的模式（和本页的关系）

在 **智能助手** 页右上角可切换三种对话模式：

| 模式 | 典型用途 |
|------|----------|
| **通用对话** | 查实时/历史传感器数据、告警、环境分析、导出等（靠工具拉数）。 |
| **知识问答**（本页说明） | 查菜单、界面、巡检与遥控**怎么用**等说明类问题（优先读内置说明文档）。 |
| **工业巡检** | 在通用能力基础上，面向**现场遥控与运维指令**；服务端会做**安全审计**与**反思**，对可能影响人身或设备的操作更谨慎。适合「帮我把车往前开」「机械臂复位」这类执行向对话；**查说明书、界面步骤**仍建议用 **知识问答**。 |

另：**巡检与遥控** 页面里还有面向「只控车/臂」的具身对话入口，与上面三种模式入口不同，但能力上有重叠；工业巡检模式与具身场景同属「要强安全」的一类。

## 做什么用

在智能助手页切换到 **「知识问答」** 后，助手会优先根据系统内置的操作说明来回答，适合：

- 各菜单、按钮是干什么的  
- 巡检、小车、云台、机械臂、告警、环境分析等 **怎么用**  
- 使用上的注意点（例如循迹时不能手动遥控等）

查实时温度、查历史曲线、导出数据等，更建议用 **「通用对话」** 或直接到 **环境监测 / 告警中心** 页面操作。

## 你需要做什么

1. 进入 **智能助手**。  
2. 点右上角 **「知识问答」**。  
3. 用日常中文描述问题即可；若回答里引用了某篇说明，会带文档名，便于你对照。

说明内容随系统版本更新；若你发现说明和实际界面不一致，请向管理员或开发反馈以便更新文案。
